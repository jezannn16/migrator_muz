Перенос лайков → YouTube Music

Из Яндекс.Музыки, в том же порядке, без лазанья в код.

1 Авторизация YouTube Music не готово

Открой music.youtube.com залогиненным → F12 → вкладка Network → фильтр browse → кликни любой запрос /browse → Headers → Request Headers → скопируй всё и вставь сюда.

Подробнее, что копировать

Нужны «сырые» заголовки запроса целиком (там будут cookie, authorization и др.). Выдели весь блок Request Headers, скопируй, вставь в поле ниже.

2 Токен Яндекса не введён

Нажми кнопку, авторизуйся, тебя перекинет на адрес с #access_token=… — скопируй значение токена и вставь сюда.

Получить токен Яндекса →

Токен = доступ к аккаунту. Хранится только в этой вкладке, на сервер уходит лишь на время переноса.

# Перенос лайков Yandex Music → YouTube Music

Браузерный интерфейс. Вставляешь токены, жмёшь **Старт**, смотришь живой прогресс. В код лезть не нужно.

Переносит лайки **в том же порядке**, в котором добавлял, с умным мэтчингом и возобновлением после обрыва.

## Запуск

**Просто двойной клик по `start.bat`** — он поставит зависимости и откроет интерфейс в браузере (`http://127.0.0.1:5000`).

Или вручную:
```powershell
cd D:\мигратор
pip install -r requirements.txt
python app.py
```

Дальше всё в браузере — три шага на странице:

### Шаг 1. Авторизация YouTube Music
1. Открой <https://music.youtube.com> залогиненным.
2. `F12` → вкладка **Network** → в фильтр впиши `browse`.
3. Кликни любой запрос `/browse` → **Headers** → блок **Request Headers**.
4. Скопируй заголовки целиком, вставь в поле на странице → **Сохранить авторизацию YT**.
   Бейдж станет «готово».

### Шаг 2. Токен Яндекса
1. Кнопка **«Получить токен Яндекса»** на странице → авторизуйся.
2. Перекинет на адрес с `#access_token=…` — скопируй значение токена.
3. Вставь в поле на странице.

### Шаг 3. Настройки и старт
- Название плейлиста, приватность, строгость совпадения, доп. лайк.
- **▶ Старт** — поехали. Прогресс-бар, счётчики, живой лог, кнопка **Стоп**.
- По ходу/в конце: кнопка **Открыть плейлист**, скачать `report.csv` и `misses.csv`.

## Как сделано хорошо

- **Порядок** — лайки тянутся с датой добавления, сортируются старые→новые, льются в плейлист (вставка хранит порядок точно).
- **Мэтчинг** — не первый результат, а скоринг: схожесть названия + исполнителя + **сверка длительности** (±15 c). Ниже порога → в `misses.csv`.
- **Возобновление** — прогресс в `state.json`. Оборвалось / закрыл вкладку — запусти снова, продолжит с места, дубли не плодит. Хочешь заново — галка «Начать заново».

## Настройки на странице

| Настройка | Что меняет |
|---|---|
| Строгость совпадения | Выше → точнее, но больше уйдёт в «не найдено». Дефолт `0.62`. |
| Ещё и жать «Мне нравится» | Кроме плейлиста ставит лайк каждому (вдвое дольше). Порядок и так держит плейлист. |
| Начать заново | Сбрасывает `state.json`, перенос с нуля. |
| Приватность | Приватный / по ссылке / публичный. |

## Безопасность

- Сервер слушает только `127.0.0.1` — из сети недоступен.
- Токен Яндекса = доступ к аккаунту. Не публикуй, не коммить. В git не добавляй `state.json`, `browser.json`, `report.csv` — там личные данные.

## Если что-то не так

- **Много «не найдено»** — глянь таблицу на странице / `misses.csv`. Понизь строгость и запусти снова (обработает только новое; для полной переоценки — «Начать заново»).
- **YT ругается на частоту запросов** — в `core.py` подними `sleep` в `DEFAULTS` до `1.0`.
- **Авторизация YT «протухла»** — повтори шаг 1 (заголовки живут не вечно).

Токен можно получить тут: ссылка → скопировать access_token из адреса после входа.

2 Вход в YouTube Music не выполнен
⚠ Рабочий способ — вход по заголовкам. Google OAuth у ytmusicapi сейчас отдаёт HTTP 400 на все запросы (баг библиотеки).

Вход по заголовкам: открой music.youtube.com залогиненным → F12 → вкладка Network → в фильтр впиши browse → кликни любой запрос /browse → Headers → блок Request Headers → скопируй весь блок сюда.

Запасной способ: вход через Google OAuth (сейчас часто не работает)
  1. Открой Google Cloud Console → создай проект.
  2. APIs & Services → Library → включи YouTube Data API v3.
  3. OAuth consent screen / Audience → тип External, добавь себя в Test users.
  4. Credentials → Create credentials → OAuth client ID → тип TVs and Limited Input devices.
  5. Скопируй Client ID и Client secret сюда.
Открой страницу и введи код:
—
Открыть google.com/device ↗
Жду подтверждения…
